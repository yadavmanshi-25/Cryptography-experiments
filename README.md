## 🛠 Tools & Technologies

- **Java SE (JCA / JCE)** – Cryptographic algorithms, encryption, hashing, and key exchange.
- **OpenSSL** – RSA key generation, digital signatures, hashing, and certificates.
- **CrypTool 2.1 & CrypTool Online** – Classical and modern cryptography analysis and visualization.
- **Wireshark** – Network packet capture, HTTP/HTTPS analysis, and TLS inspection.
- **OpenVPN** – VPN connectivity and encrypted network traffic analysis.
- **Git & GitHub** – Version control and lab documentation.
